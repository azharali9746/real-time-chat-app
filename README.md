# Real-Time Chat Application

A simple chat application developed using PHP, HTML, and CSS to explore web-based communication and client-server interaction.

## 📌 Project Overview

The Real-Time Chat Application provides a basic interface for users to exchange messages. This project demonstrates server-side programming using PHP and the development of a web-based user interface.

## ✨ Features

- Simple and user-friendly chat interface
- PHP-based message handling
- CSS styling for the user interface
- Login or entry page
- Logout functionality
- Message storage using a text file

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Storage:** Text file (`messages.txt`)
- **Local Server:** XAMPP / Apache

## 📂 Project Structure

```text
real-time-chat-app/
├── chat.php
├── index.php
├── logout.php
├── style.css
├── messages.txt
└── LAN_Talk_Report.pdf
```

## 🚀 How to Run the Project

1. Install [XAMPP](https://www.apachefriends.org/).
2. Copy the project folder into the `htdocs` directory.
3. Start Apache from the XAMPP Control Panel.
4. Open your browser and visit:

   `http://localhost/real-time-chat-app/`

5. Use the application through the available interface.

## 🎯 Learning Objectives

- Understand PHP server-side programming.
- Learn how web applications handle user input.
- Explore basic client-server communication.
- Understand file-based message storage.
- Practice integrating HTML, CSS, and PHP.
